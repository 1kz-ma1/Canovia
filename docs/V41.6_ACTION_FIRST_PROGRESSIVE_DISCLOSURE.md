# V41.6 Action First / Progressive Disclosure

## 調査と対象

基準はPR #73マージ後のmain（9d4c687）。Homeの実体はdashboard/index、Plan Hubはその中の計画タブ。plans/showは計画詳細であり今回の再設計対象には含めない。

Homeでは共同計画が今日の行動より先にあり、推薦カードでは優先度・理由・Tool説明がCTAより先に並んでいた。Plan HubはV41.2のSurface Engineで構成されるため、その選定・順序・visibility契約は変更せず表示層で段階開示する。

## 情報階層

- Primary：作業中・中断中の再開、今日のTask、実行CTA、面接準備・振り返り・未整理Captureの行動導線。
- Secondary：Plan名、Task名、状態、時間目安、進捗、期限。Plan Toolsは常時利用可能。
- Tertiary：推薦理由、優先度判定、Tool説明、Task説明、学習分析、Evidence、選考状況、Task一覧、履歴。

Homeの行動領域を補助操作・共同計画より前に配置。進捗概観と共同計画は見出しから開く。推薦CTAの後に「なぜこの行動？・進め方」を配置する。

Plan Hubでは次Actionの先頭80文字までを最低限の文脈として残し、Task説明・次Action全文は実行CTAの後から開く。Plan説明は従来の2行切り捨てをやめ全文を開示する。Surfaceのうちstudy_focus、delivery_focus、recent_evidence、task_list、recent_activity、career_pipeline、career_result_waitingを初期折りたたみとする。current_task、plan_tools、面接関連Action、Capture Inboxは折りたたまない。未知の将来Surfaceも既定ではそのまま表示する。

## 操作と互換性

ネイティブdetails/summaryを使い、Enter・Space・タップで開閉可能とする。独自aria-expandedは重複管理しない。JavaScriptなしでも詳細本文へ到達でき、保存や再計算を伴わない。開閉状態は保存せず再読み込み時に初期化する。

情報・既存URL・フォーム・CSRF・権限判定・推薦順位・Evidence取得上限・offline snapshotを維持する。AI Practice / Career Workspace / Roadmap本体、課金・Entitlement・AI Capacity・進捗計算は変更しない。migrationなし。

## 回帰確認

Homeの行動順序、CTAが閉じたdetailsの外にあること、理由と本文の保持、Surface開示と常設入口、空Plan・完了Task・閲覧者権限を確認する。既存Guidance / Adaptive Surface / Execution Evidence / Career / Practice / Economyの回帰とfrontend buildを実施する。全体suiteの失敗は同環境の基準mainと比較する。

## Content policy

V40.3.1 applies `docs/QUESTION_PACK_CONTENT_RULES.md` (rules version 1.1).

The most important rule is context fidelity: when a problem pattern is derived from past-exam style material, numerical values may change, but the natural meaning domain, business/technical context, and standard examination terminology should not be replaced by artificial abstractions.

Example: a Bayesian medical-screening question should keep a natural disease / test / positive-result context instead of rewriting it as an abstract "abnormal object" scenario.

The Pack does not bundle a large verbatim copy of the IPA PDF.

Instead it contains:

### derived

Canovia-original practice questions whose concept and answer basis was checked against a published IPA past question.

Each derived question stores a source reference such as:

`参考：令和7年度 秋期 応用情報技術者試験 午前 問32（Canoviaオリジナル類題）`

### canovia_original

Questions created specifically for Canovia where no individual past-question source is used.

Examples include the additional MTU and DNS reinforcement questions.

This distinction is persisted in `source_type`.

---

## Source basis

Primary public reference:

- 令和7年度 秋期 応用情報技術者試験 午前 問題
- 令和7年度 秋期 応用情報技術者試験 午前 解答例

Pack metadata retains the source problem and answer URLs.

IPA's published guidance says that public past questions can be used for educational problem sets without individual permission or usage fees, while copyright remains with IPA and source attribution is required. Modified material must indicate that it has been modified.

The Pack therefore stores source references for derived questions and identifies them as Canovia-original exercises rather than presenting them as verbatim official questions.

## Weakness coverage

V40.2 requires at least three questions matching a focus topic before a Pack can replace the external-AI fallback.

V40.3 deliberately guarantees starter coverage for:

### MTU計算

- maximum IPv4 payload under an MTU
- TCP MSS calculation
- fragmentation count calculation

### DNSレコード

- MX
- CNAME
- PTR

### DB / データベース

Includes:

- views
- MVCC
- indexes
- NoSQL / BASE
- normalization
- transaction isolation

### Calculation

Includes:

- M/M/1
- availability
- scheduling
- sampling
- performance
- communication error expectation

This means a single current weakness such as `MTU計算`, `DNSレコード`, or `DB` can still satisfy Question Bank Coverage.

## Answer UI

Every question has:

1. required `single_choice`
2. optional `reasoning` textarea

If the learner only chooses an answer:

```
Canovia deterministic grading
```

If the learner also writes reasoning:

```
trusted grading rule
+ external AI reasoning feedback
```

This keeps direct grading fast while preserving deeper thought-process feedback when requested.

## Native Japanese choice IDs

V40.3 expands choice identifiers from ASCII-only values to Unicode letters/numbers.

Valid examples now include:

- A / B / C / D
- ア / イ / ウ / エ

Question ids and response-field ids remain restricted separately.

This allows Japanese qualification content to preserve its normal answer symbols.

## Qualification routing

The AP Pack uses qualification-specific match terms only:

- 応用情報

This preserves V40.2's rule that a generic subject name must not make one qualification Pack eligible for another qualification.

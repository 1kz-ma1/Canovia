# V40.4.3 Unified AI Handoff UI

## Goal

V40.4 initially simplified the AI Practice handoff.

V40.4.3 applies the same interaction contract to the remaining external-AI workflows so Canovia no longer has a mix of:

- large raw Prompt textareas
- large raw JSON textareas
- one-click handoff UI

The user should not have to read machine payloads during normal operation.

---

## Unified interaction contract

### Prompt side

Normal view:

```
[Promptをコピー]
[このPromptに含まれる情報 ▼]
```

Raw Prompt:

- remains exact
- remains available to copy
- is not part of the normal visual hierarchy

### JSON return side

Normal view:

```
[クリップボードから貼り付けて確認]
[手動で貼り付ける / JSONを確認する ▼]
```

Supported browsers:

1. read clipboard
2. fill the existing form field
3. submit the existing form
4. use the existing server-side normalizer/validator

Unsupported/denied clipboard access:

1. open manual fallback
2. focus the existing textarea
3. keep the old workflow available

## Updated surfaces

### Plan review / update

`resources/views/plans/review_assistant.blade.php`

Updated:

- generated update Prompt
- operations JSON return
- JSON repair Prompt

Prompt summary includes:

- Plan / Task
- progress / deadline / availability
- recent work
- optional activity summary
- Future Memo context
- allowed update operations
- authoritative IDs
- JSON safety constraints

### Policy change

Both:

- `resources/views/plans/policy_change.blade.php`
- `resources/views/chat/partials/policy_change.blade.php`

Updated:

- policy-change Prompt
- operations JSON return

### Resource assistant

`resources/views/resources/assistant.blade.php`

Updated:

- resource-assignment Prompt
- assignment JSON return

The summary explicitly mentions that registered resource URLs may be included in the external-AI Prompt.

### AI context sharing

`resources/views/chat/partials/ai_context.blade.php`

Updated:

- raw context Prompt is hidden from the normal layout
- copy / copy-and-mark operations remain
- a compact information summary replaces the large textarea

This flow does not return JSON, so it has no paste step.

---

## Intentionally unchanged

### Universal AI import

`resources/views/home.blade.php`

The Universal AI import already places JSON entry behind a `details` disclosure.

It is therefore not part of the V40.4.3 cleanup.

### Server contracts

No changes to:

- JSON schema
- PlanReviewAssistantController
- policy-change semantics
- Resource assistant schema
- AI context export semantics
- normalization / validation
- mutation idempotency

This release is a presentation and interaction cleanup.

---

## Central clipboard behavior

Copy/paste behavior continues to live in:

`resources/js/app.js`

Paste uses:

- `data-paste-target`
- `data-paste-submit`
- `data-paste-fallback`
- `data-paste-status`

The individual views no longer need their own clipboard JavaScript for standard copy/paste.

AI context keeps its specialized copy-and-mark behavior because copying also records the context export point.

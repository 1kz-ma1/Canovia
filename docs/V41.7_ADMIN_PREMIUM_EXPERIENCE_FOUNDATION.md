# V41.7 Admin & Premium Experience Foundation

## 目的

V41.7は、Native AIや決済を入れる前に、運営者・Free・Premiumの体験を安全に分離し、実際のPremium価値を検証できる土台を作る。

今回の責務は次の4つを混ぜないこと。

```text
AdminAccessService
  -> 運営者か

FeatureAccessService
  -> このFeatureを使えるか

ProductGrantService
  -> Premium等の商品権利を持つか

AdminPreviewContext
  -> Super AdminがFree/Premium体験を確認中か
```

## Super Admin

CanoviaのSuper Adminは1アカウントだけとする。

- 第一識別子: `CANOVIA_SUPER_ADMIN_USER_ID`
- 移行期間だけ `CANOVIA_ADMIN_EMAIL` をfallbackとして利用
- IDが設定されている場合、emailは管理者判定に使用しない
- DBの `is_admin` フラグや管理者昇格UI/APIは作らない
- 管理パスワードを知っているだけではAdminになれない
- `/admin/*` はserver-side `admin.access` middlewareで保護する

本番ではsession flagをAdmin認可に使わない。旧テスト互換のsession認可はtesting environmentだけに限定する。

## Super Admin access

通常のAdmin表示ではSuper Adminはすべての `FeatureKey` を利用可能とし、AI Capacityは検証用にboostedとして扱う。

これはProduct Grantではない。AdminをPremium購入者やAll Access所有者として保存せず、`EntitlementSource::Admin` と `reason=super_admin` で監査可能にする。

## Settings Hub

従来の「表示」入口を「設定」へ変更し、既存のテーマ・アクセント・表示密度を「表示」セクションとして保持する。

設定には以下をまとめる。

- アカウント
- 利用プラン
- 表示
- 使い方 / ホーム画面追加
- Super Adminだけの管理者メニュー
- Super AdminだけのFree / Premium / Admin表示プレビュー

一般ユーザーには管理者入口を描画しない。入口の非表示とは別に、server-side Admin認可も必須とする。

## Complimentary Premium

身近なユーザー・テスターへ、決済なしで `Premium Core` を付与できる。

```text
Admin
  -> Complimentary Premium
  -> user_product_grants
     product_key = premium_core
     source = complimentary
  -> ProductGrantEntitlementResolver
  -> FeatureAccessService
```

期間:

- 無期限
- 30日
- 90日
- 任意期限

日常用の無償付与UIはPremium Coreだけを対象とし、All Access / Purpose Pack / AI Capacity Boostは同じ操作から付与しない。既存Economy Inspectorの開発用Product Grant操作は検証用として残す。

解除時はrowを削除せず `expires_at` を現在時刻へ更新し、metadataへ解除情報を残す。これにより最低限の付与履歴を保持する。

Complimentary PremiumはPremium Feature Accessだけを与え、AdminAccessは一切与えない。

## Admin Preview

Super Adminは権限そのものを書き換えず、session-scopedなPreview Contextで表示・Feature Accessを確認できる。

- Admin: 全Feature + boosted capacity
- Free: Free Entitlementとして評価
- Premium: Free + Premium Coreとして評価、AI Capacityはstandard
- Preview中も `AdminAccessService` はSuper Adminのままなので、管理画面へ戻れる

## 非対象

V41.7では以下を実装しない。

- Native AI実行
- StoreKit / Stripe
- 公開Pricing / Paywall
- Pro / All Accessの通常ユーザー向け購入
- AI使用量metering
- Admin複数人化

Native AI Practiceは次段階でPremium Coreの実価値として接続する。

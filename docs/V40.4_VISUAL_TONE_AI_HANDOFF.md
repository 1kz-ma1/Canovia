# V40.4 Visual Tone & AI Handoff UX

## Goal

V40.4 addresses two presentation problems:

1. Canovia's interface had a strong visual world, but the typography still felt generic and administrative.
2. External-AI handoff screens displayed very large Prompt / JSON textareas even though most learners only need to copy or paste them.

The change keeps the underlying V40.1–V40.3 orchestration contract unchanged.

---

## Typography

### Trial font

V40.4 uses **Klee One** as Canovia's first-choice UI font.

Fallback order:

```
Klee One
→ Yu Kyokasho / YuKyokasho
→ Hiragino / Noto / system sans
```

The intent is not decorative handwriting. The font should feel authored and human while remaining usable for long Japanese study content.

### Machine-readable content

The following continue to use a monospace stack:

- JSON
- code
- raw machine payloads
- elements explicitly using `font-mono`

The handwritten treatment must never reduce JSON readability.

### Offline / PWA behavior

Klee One is loaded as a web font with `display=swap`.

If the font cannot be fetched, Canovia remains fully usable with local/system fallback fonts.

There is no runtime dependency on the font for application behavior.

## AI Practice handoff

### Before

The external-AI flow showed:

- a large generation Prompt textarea
- a large question JSON textarea
- a large evaluation Prompt textarea
- a large assessment JSON textarea

The learner usually does not need to read these payloads.

### After

Generation Prompt:

```
[演習準備プロンプトをコピー]
[このプロンプトに含まれる情報 ▼]
```

Question JSON:

```
[クリップボードから貼り付けて読み込む]
[手動で貼り付ける / JSONを確認する ▼]
```

Evaluation Prompt:

```
[評価プロンプトをコピー]
[この評価依頼に含まれる情報 ▼]
```

Assessment JSON:

```
[クリップボードから貼り付けて確認]
[手動で貼り付ける / 評価JSONを確認する ▼]
```

Raw Prompts still exist in hidden form controls so the existing copy mechanism can use the exact server-generated text.

They are not part of the normal visual hierarchy.

---

## One-click paste

V40.4 adds delegated `data-paste-target` handling in `resources/js/app.js`.

On a supported secure browser:

1. user copies the JSON in the external AI
2. user taps the Canovia paste button
3. Canovia reads clipboard text
4. Canovia fills the existing form field
5. Canovia submits the form automatically

No additional paste or submit action is needed.

### Fallback

Clipboard reads can fail because of:

- browser capability
- permission policy
- insecure context
- platform-specific restrictions
- empty clipboard

When that happens:

1. the manual `details` section opens
2. the textarea receives focus
3. Canovia explains that manual paste is required

The existing server-side JSON normalizer and validation remain authoritative.

---

## Prompt summaries

The collapsed information summary explains the payload contract instead of exposing the whole text.

Generation summary includes:

- Plan / Task context and IDs
- Practice Strategy and focus
- recent learning history / weaknesses
- target question count and response UI contract
- JSON safety constraints

Assessment summary includes:

- questions and learner answers
- reasoning / calculation text when present
- trusted Question Bank grading context when present
- assessment response contract
- Plan / Task safety constraints

This preserves transparency without forcing raw machine text into the learner's normal workflow.

---

## Repair flow

Question/assessment repair Prompts are also visually hidden.

The learner sees:

- error explanation
- one-click repair Prompt copy
- a collapsed summary of what the repair request contains

The underlying repair Prompt still includes the original JSON, original Canovia Prompt, error, and authoritative Plan / Task IDs.

---

## Scope

V40.4 does not change:

- StudyPracticeSession lifecycle
- Provider routing
- Question Bank selection
- grading rules
- Prompt semantics
- JSON schema
- Task progress application

It is a presentation and interaction update.

---

## Font alternatives considered

If Klee One proves too handwritten during real use:

- **Zen Kaku Gothic New**: cleaner and more futuristic, lowest reading risk
- **Zen Kurenaido**: more handwritten/personable, stronger style but more fatigue risk
- **BIZ UDPGothic**: highly readable and practical, weaker world-building but excellent for study text

Klee One is the first trial because it sits between expressive handwriting and textbook readability.

## Regression checks

- external-AI generation still exposes the exact copy action
- question JSON still posts through the existing `questions_json` field
- assessment JSON still posts through `assessment_json`
- repair flows still preserve their exact Prompt
- direct Question Bank flow does not render external-AI handoff UI
- browser clipboard failure always exposes manual paste

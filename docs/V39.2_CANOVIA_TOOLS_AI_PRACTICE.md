# V39.2 Canovia Tools / AI Practice MVP

## Purpose

Canoviaの「作業開始」をタイマーだけに限定せず、Taskの内容に合う道具をその場で使えるようにする。

## Tool foundation

PlanToolService が Plan category / Task content / linked resources を見て利用可能Toolを返す。

Initial tools:

- timer: 全ての編集可能な未完了Task
- ai_practice: 資格学習Plan
- resources: Planの関連資料
- artifacts: 個人開発 / ゲーム開発 / 制作活動

ToolはTaskを達成する手段であり、Taskそのものや推薦ロジックとは分離する。

## AI Practice MVP

1. Task文脈入りの問題生成PromptをCanoviaが作る
2. 外部AIが study_practice JSONを返す
3. Canoviaがtarget_plan / target_taskを検証して問題UIを表示
4. ユーザーがCanovia内で回答
5. Canoviaが問題+回答を評価Promptへ変換
6. 外部AIがstudy_assessment JSONを返す
7. Canoviaでscore / strengths / weaknesses / 推奨進捗 / next actionをプレビュー

## Safety boundary

V39.2ではassessmentをTaskへ自動反映しない。

次段で永続化・request_hashによる冪等性・ユーザー確認後のapplyを実装してから、
Task progress / learning outcome / next actionへ反映する。

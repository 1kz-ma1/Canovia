# V39.3 Study Practice Learning Loop

AI演習を一時的なクイズ画面ではなく、Task達成の学習証跡としてCanoviaへ戻す。

## Persistent attempt

study_practice_attempts stores Plan / Task, user_id or guest actor_token, immutable request_hash, questions / answers / assessment, score / strengths / weaknesses, recommended Task progress, evidence summary / next action, applied progress before / after, and applied_at.

## Apply rule

Assessment JSONの読み込みだけではTaskを変更しない。ユーザーが「Taskへ反映」を押したときだけtransaction + row lockで更新する。

- same request_hash => same StudyPracticeAttempt
- applied_at present => no-op on retry
- AI assessment alone never lowers existing Task progress
- progress 100 => Task done / remaining 0
- evidence_summary => progress_reason
- next_action => next_action_note

## Adaptive next practice

The five most recent personal attempts are included in the next generation prompt. Weaknesses and next actions therefore become context for the following exercise.

## Timeline

Applied AI practice attempts are included in the Plan timeline as study events.
